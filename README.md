Task 2 — Predictive Linear Regression Model

Project Overview

This project implements a supervised machine learning regression pipeline to predict house prices using the House Prices dataset.

The project demonstrates a complete machine learning workflow, including data loading, preprocessing, feature transformation, Ridge Regression, prediction, and model evaluation.

Objective

The objective is to build a regression model that predicts a continuous numerical value using Scikit-Learn.

Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn
* Google Colab

Machine Learning Workflow

1. Load the House Prices dataset
2. Explore the dataset
3. Check missing values
4. Separate features and target
5. Split data into training and testing sets
6. Handle missing numerical values using mean imputation
7. Handle categorical values using imputation and one-hot encoding
8. Scale numerical features using StandardScaler
9. Train a Ridge Regression model
10. Generate predictions
11. Evaluate the model using R² and RMSE
12. Visualize actual and predicted values

Model

The project uses Ridge Regression, a regularized form of linear regression.

Evaluation Metrics

The model is evaluated using:

* R² Score
* Root Mean Squared Error (RMSE)
